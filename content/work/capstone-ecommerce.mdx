## Context

My BSc final-year project at HK PolyU: an e-commerce application where checkout
settles in cryptocurrency through Ethereum smart contracts instead of a
traditional payment gateway. Designed and built solo — the Solidity contract, the
React front end, and the Web3.js integration between them, deployed on Firebase.
